Finora Quantitative Methodology & Mathematical Formulations
Strict academic standards: zero data leakage, CAGR standardization, residual policy design

1. Data Partitioning Protocol (Zero Leakage)

To eliminate prior train/test leakage, the data is partitioned into three strict time buckets:

  • Train: 2015-01-02 to 2021-12-31 (1,762 trading days) — Feature scalers, GNN architectures, and RL policy training.
  • Validation: 2022-01-03 to 2022-12-28 (249 trading days) — Hyperparameter tuning ($\alpha$, $\lambda_{\text{vol}}$, $\lambda_{\text{txn}}$) only.
  • Holdout Test: 2022-12-29 to 2024-12-31 (504 trading days) — Evaluated strictly once at the end.

2. Residual Policy Formulation

Direct softmax output ($w = \text{softmax}(a)$) creates exploratory instabilities in high-dimensional continuous action spaces (20 assets + 1 cash = 21 dimensions). Finora introduces a residual action architecture anchored around an equal-weight or momentum baseline:

w = softmax( log(1 / N) + α · tanh(a) )

The hyperparameter $\alpha \in [0.10, 0.15]$ bounds maximum deviations from the disciplined prior, preventing catastrophic churn while allowing the agent to capture excess return.

3. Risk-Adjusted Turnover-Aware Reward

The environment rewards net portfolio log return penalized for localized volatility and portfolio concentration:

R_t = ln( 1 + r_port,t - λ_txn · c_t ) - λ_vol · σ_20,t^ann - λ_conc · HHI_t

where $c_t = \frac{1}{2} \sum_{i} |w_{i,t} - w_{i,t-1}|$ is one-way turnover and $\text{HHI}_t = \sum_i w_{i,t}^2$ is the Herfindahl-Hirschman concentration penalty.

4. Compound Annual Growth Rate (CAGR) Standard

All annualized returns across all baselines and RL agents strictly adhere to the compound rate equation:

Annualized Return = ( 1 + Cumulative_Return )^( 252 / N ) - 1
