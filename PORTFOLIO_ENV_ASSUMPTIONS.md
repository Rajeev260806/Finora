## 📌 Executive Summary

`PortfolioEnv` (`src/environment/portfolioenv.py`) is a fully Gymnasium-compliant reinforcement learning environment designed for portfolio allocation over a multi-asset universe ($N=20$ equities plus 1 cash asset).

In Phase 3, `PortfolioEnv` was upgraded to support **dual observation modes**:
1. `use_embeddings=False` (Default / Phase 1 & 2 mode): Returns historical asset returns windows of shape `(n_assets, window)`.
2. `use_embeddings=True` (Phase 3 & 4 mode): Returns GNN node embeddings of shape `(n_assets, embedding_dim)` (default `32`), either loaded from pre-computed `.npy` files (e.g. in `src/gnn/embeddings/`) or generated as reproducible synthetic placeholders.

## 📐 Environment Design & Mechanics

### 1. Action Space
- **Type**: `spaces.Box(low=-10.0, high=10.0, shape=(n_assets + 1,), dtype=np.float32)`
- **Interpretation**: Continuous unconstrained action logits $\mathbf{z} \in [-10, 10]^{N+1}$.
- **Weight Mapping**: Internal Softmax guarantees long-only weights summing to 1.0:
  $$\mathbf{w}_t = \text{softmax}(\mathbf{z}_t), \quad \sum_{i=1}^{N+1} w_{i, t} = 1.0, \quad w_{i, t} \ge 0$$
- **Cash Slot**: Index $N$ (`weights[-1]`) represents cash reserves. Cash earns zero return ($r_{\text{cash}} = 0$) and suffers no market risk.

### 2. Observation Space Modes
- **Mode A (`use_embeddings=False`)**:
  ```python
  spaces.Dict({
      "returns_window": Box(shape=(N, W), dtype=float32),  # W = 20 past daily returns
      "weights": Box(shape=(N + 1,), dtype=float32)        # t-1 allocation incl. cash
  })
  ```
- **Mode B (`use_embeddings=True`)**:
  ```python
  spaces.Dict({
      "gnn_embeddings": Box(shape=(N, D), dtype=float32), # D = 32 embedding features per asset
      "weights": Box(shape=(N + 1,), dtype=float32)        # t-1 allocation incl. cash
  })
  ```

### 3. Transaction Costs & Portfolio Value Dynamics
- **Turnover Calculation**:
  $$\text{Turnover}_t = \|\mathbf{w}_t - \mathbf{w}_{t-1}\|_1 = \sum_{i=1}^{N+1} |w_{i, t} - w_{i, t-1}|$$
- **Cost Deducted**: Linear transaction cost with 10 basis points baseline ($\beta = 10.0 \text{ bps} = 0.0010$):
  $$c_t = \left(\frac{\text{bps}}{10\,000}\right) \cdot \text{Turnover}_t = 0.0010 \cdot \text{Turnover}_t$$
- **Portfolio Value Update**:
  $$V_t = V_{t-1} \cdot (1 + r_{\text{port}, t} - c_t)$$
  where $r_{\text{port}, t} = \sum_{i=1}^{N} w_{i, t} r_{i, t}$.

### 4. Reward Model (Modular Phase 2 & 3 Formulation)
$$R_t = \ln(1 + r_{\text{port}, t} - \lambda_{\text{txn}} c_t) - \lambda_{\text{vol}} \sigma_{20, t}^{\text{ann}} - \lambda_{\text{conc}} \text{HHI}_t$$
- $\lambda_{\text{vol}}$: Rolling 20-day annualized portfolio volatility penalty.
- $\lambda_{\text{conc}}$: Herfindahl-Hirschman Index asset concentration penalty across risky assets ($\sum_{i=1}^{N} w_{i, t}^2$).
- $\lambda_{\text{txn}}$: Transaction cost weight multiplier.

## 🔒 Assumptions & Known Limitations

1. **Daily Resolution**: Data is sampled on a daily closing basis; intraday microstructure dynamics and bid-ask spreads are not modeled.
2. **Linear Transaction Cost**: Transaction cost is modeled linearly relative to turnover (10 bps). Market impact curves (slippage) are simplified.
3. **Long-Only Allocation**: No short-selling or leverage is permitted ($w_{i, t} \ge 0$, $\sum w_i = 1$).
4. **Zero Risk-Free Rate**: Cash earns exactly 0.0% interest.
5. **No Look-Ahead Bias**: At step index $t$, observations contain strictly past realized returns up to $t$ (exclusive of $t+1$).
6. **Stationary Universe**: The stock universe is fixed at $N=20$ assets throughout each episode.

## 🤝 Person A (GNN Lead) Phase 4 Handoff Interface

To integrate real GNN embeddings generated by Person A in Phase 4:

1. **Embedding File Format**:
   - Files saved as NumPy binary `.npy` arrays in `src/gnn/embeddings/`.
   - Array shape: `(20, 32)` or `(N, D)` where $N=20$ and $D=32$ (float32).
   - Filename convention: `embedding_{idx:04d}.npy` or `embeddings_graph_{idx:04d}.npy`.
2. **Activation Code**:
   ```python
   env = PortfolioEnv(
       data=train_df,
       use_embeddings=True,
       embedding_dim=32,
       embedding_dir="src/gnn/embeddings/",
       lambda_vol=0.10,
       lambda_conc=0.01
   )
   ```
3. **Fallback Behavior**: If a file is missing or `embedding_dir` is omitted during testing, `PortfolioEnv` automatically falls back to reproducible synthetic Gaussian placeholder embeddings without breaking execution.
