# GNN Embedding Specifications for Person B's RL Environment

## Overview
This document specifies the format, structure, and usage of the node embeddings generated by Person A's GNN model in Phase 3. These embeddings are designed to be used as input features in Person B's `GNNPortfolioEnv` for reinforcement learning training in Phase 4.

## Embedding Generation Process
- **Model**: 2-layer Graph Convolutional Network (GCN) trained via proxy task (next-day return prediction)
- **Architecture**: GCNConv(5, 64) → ReLU → Dropout(0.2) → GCNConv(64, 32)
- **Input**: Node features (5-dimensional: returns, volatility, volume, etc.) and edge weights (correlation values)
- **Output**: 32-dimensional node embeddings for each stock in the universe
- **Training Data**: Temporal graph snapshots of financial correlation networks (2015-03-31 through 2022-12-28)
- **Proxy Task Performance**: R² = -115.26, MAE = 0.087 (on next-day return prediction)

## Embedding Format
- **Storage**: Individual NumPy files (`.npy`) in `src/gnn/embeddings/`
- **Naming Convention**: `embeddings_graph_{index:04d}.npy`
  - Index corresponds to the temporal order of graph snapshots
  - Index 0: Earliest snapshot (2015-03-31)
  - Index 1951: Latest snapshot (~2022-12-28)
- **Shape**: `[num_nodes, embedding_dim] = [20, 32]`
  - 20 nodes (stocks) in consistent alphabetical order by ticker
  - 32-dimensional embedding vector per node
- **Data Type**: 32-bit floating point (float32)
- **Normalization**: Embeddings are not normalized post-generation. They retain the scale from the GNN output (typically small values centered around 0).

## Temporal Alignment
- Each embedding file represents the node embeddings for a specific date (the date of the graph snapshot)
- The embeddings are **descriptive** of the graph structure at time `t` (based on data up to and including time `t`)
- For use in the RL environment at time `t`, load the embedding file corresponding to time `t`
- The embeddings can be used to predict or inform decisions about time `t+1` (as they were trained to capture predictive signals for next-day returns)

        numpy array of shape [20, 32] containing node embeddings
    """

## Stock Order Consistency
The node ordering in the embeddings is **consistent across all time steps** and matches the alphabetical ordering of tickers used in the graph construction process. Person B must ensure that the portfolio environment maintains the same stock ordering when aligning embeddings with asset returns, weights, etc.
