# Project Documentation

This directory contains documentation and guides for the ML_Package project.

## Guide Files

The `_GUIDE.md` files contain detailed instructions for each person's responsibilities in each phase of the project:

- `PHASE_X_PERSON_Y_GUIDE.md`: Guide for Person Y's responsibilities in Phase X
- `PHASE_X_REWARD_MODEL.md`: Specific guide for reward modeling in Phase X

## Other Documentation

- `phase_wise_split.md`: High-level phase-wise plan for the project
- `project_ideas.md`: Initial project ideas and concepts
- `project_notes.md`: Ongoing project notes and observations
